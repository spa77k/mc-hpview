**English** | [日本語](SECURITY.ja.md) | [简体中文](SECURITY.zh-CN.md) | [한국어](SECURITY.ko.md)

## Supported versions

Only the latest release on the [Releases](https://github.com/spa77k/mc-hpview/releases) page receives fixes.

## Reporting a vulnerability

Do not report security problems in public issues.

Use [Report a vulnerability](https://github.com/spa77k/mc-hpview/security/advisories/new) on GitHub to send a private report. Please include:

- what an attacker can do
- steps to reproduce
- your Paper and HPView versions

You will get a reply within 7 days. Once a fix is released, the report may be published as a security advisory.
